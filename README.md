# Deepfake Detection System

An AI-based system to detect fake videos and audio using deep learning techniques.

## Project Overview

This project analyzes uploaded videos and classifies them as REAL or FAKE using AI models.

## Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- FastAPI
- Python

### AI Model
- Xception CNN
- LSTM/GRU
- PyTorch
